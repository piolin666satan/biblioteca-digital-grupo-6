2. Actualización de DTOs
Se modificó el objeto de transferencia de datos del Cliente para soportar el flujo de autenticación y registro.

Archivo modificado: ClienteDTO.java

Cambios aplicados:

Se añadió el atributo password de tipo String.

Se documentó el nuevo campo con las anotaciones @Schema de Swagger (description, example, requiredMode).

Se incluyó la validación @NotBlank
(message = "La contraseña es obligatoria") para asegurar que no lleguen nulos a la base de datos.


3. Ajustes en la Lógica de Negocio (Service)
Se corrigió un error 500 (null value in column "password") ajustando el mapeo manual entre el DTO y la Entidad en la implementación del servicio.

Archivo modificado: ClienteServiceImpl.java

Cambios en mapearEntidad() (Entrada de datos):

Se agregó la lógica para capturar la contraseña enviada desde el frontend/Postman: entidad.setPassword(dto.getPassword());.

(Nota de desarrollo: Se desactivó temporalmente el passwordEncoder.encode() para propósitos de pruebas locales y visualización del flujo de datos en texto plano).

Cambios en mapearDTO() (Salida de datos):

Se agregó la línea dto.setPassword(entidad.getPassword()); para permitir
que el JSON de respuesta devuelva la contraseña y confirmar su persistencia en PostgreSQL.
